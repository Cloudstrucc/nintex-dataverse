{% comment %} EC-GCWeb-Validation (global, reusable - included once from EC-Scripts-Base) Makes EVERY Power Pages Basic Form / entityform on the site produce a WCAG 2.1 / GCWeb (WET-BOEW) accessible error experience, with NO per-form or per-field code. A maker just adds a Basic Form and sets the field's validation in Dataverse (Required, or a validation rule). Power Pages renders standard ASP.NET validators; this module then, on each failed validation: 1. Replaces the plain ASP.NET validation summary with a WET-BOEW error summary - role="alert", an

stating the error count, and an ordered list of IN-PAGE LINKS. Clicking a link moves focus to (and scrolls to) the offending field. 2. Marks each invalid field aria-invalid="true" + a red "invalid" style, and links it to its message via aria-describedby. Field -> message mapping uses ASP.NET's own Page_Validators registry (validator.controltovalidate = the input id), so it is reliable regardless of the summary markup, with a label-text fallback. Opt a form out with class "no-gcweb-validate" on the form (or any ancestor). {% endcomment %}
