{% comment %} EC-Subgrid-Modern-Scripts (global; included once from EC-Scripts-Base) Progressive enhancement for basic-form subgrids ONLY (.entity-grid.subgrid). Adds a Cards/Table toggle and (in Table mode) an add/remove-columns menu. DOM-only, idempotent, re-applied on each grid re-render (pagination fires the entitygrid "loaded" event / mutates .view-grid), so OOB pagination and the OOB row-action handlers are reused as-is — presentation only, no new CRUD. data-ecw-modal="1" -> also injected into modal-form iframes so subgrids in modals match. Configurable via content snippets (English fallbacks so it works before they exist): EC/Subgrid/ViewCards, EC/Subgrid/ViewTable, EC/Subgrid/Columns -> button labels EC/Subgrid/DefaultView -> 'cards' (default) | 'table' EC/Subgrid/InitialColumns -> how many columns Table shows before the menu (default 2) Page size is NOT set here — it stays whatever the subgrid's own "Records per page" is. {% endcomment %}
